# Layout

This repository is a flat list of projects. Every project owns a directory, and
that directory holds everything the project needs: its source, its tests, its
docs and its own licence.

## The projects

- `treepy/` — the directory tree printer. A Python package with a CLI, its
  tests, its docs and a small example set.
- `raf/` — the read-later shelf. A Python package, a sqlite schema document and
  the usual tests.
- `masrouf/` — the expense tracker. A static page, a handful of ES modules and
  the tests that run on `node --test`.
